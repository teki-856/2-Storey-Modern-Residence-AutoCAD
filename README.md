# 2-Storey Residential House | AutoCAD

## Overview
This project showcases the architectural floor plans of a modern two-storey residential house created using Autodesk AutoCAD. The design includes detailed room layouts, furniture placement, staircase planning, and functional space utilization.

## Features
- Ground Floor Plan
- First Floor Plan
- Living & Dining Area
- Kitchen Layout
- Bedrooms
- Bathrooms
- Staircase
- Terrace
- Furniture Layout

## Software Used
- Autodesk AutoCAD

## Skills Demonstrated
- 2D Architectural Drafting
- Residential Space Planning
- Technical Drawing
- CAD Documentation
